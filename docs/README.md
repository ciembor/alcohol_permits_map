# Project documentation

This directory contains stable documentation artifacts for the repository.

- `deployment.md` describes the production deployment assumptions and workflow.
- `erd.pdf` is the current Rails model ERD generated with `rails-erd`.
- `point_grouping_flowchart.mmd` is the Mermaid source for the public dataset
  processing flow.
- `point_grouping_flowchart.svg` is the rendered flowchart for use in documents.
- `images/latest-alcohol-sales-points-map.png` is the README preview image that
  links to the public map.

Working notes, one-off audits, generated review checklists, and historical
research drafts should not be committed here. Put temporary audit output under
`tmp/` or regenerate it when needed.
